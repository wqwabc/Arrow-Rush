# 一箭又一箭（Arrow Escape）

一个用 Python + Pygame 实现的休闲解谜小游戏，玩法参考微信小游戏《一箭又一箭》。

棋盘上散布着带方向的箭头。点一下箭头，它就会沿着自己的方向前进：**前方一路畅通就飞出棋盘被消除，前方有箭头挡着就飞不出去，并且消耗一次失误机会**。把整盘箭头清空即可通关，失误次数耗尽则本关失败。

12 个关卡分三档难度，带计时、计分、提示、撤销、选关与自动存档。

---

## 快速开始

### 环境要求

| 项目 | 要求 |
|---|---|
| Python | 3.8 及以上（开发环境为 3.13.3） |
| Pygame | 2.1 及以上（开发环境为 2.6.1） |
| NumPy | **可选**。装了只是让音效生成快一倍（46ms vs 86ms），不装也能正常玩 |
| 音频设备 | 可选。没有声卡或驱动不可用时游戏照常运行，只是没有音效 |

**不需要任何图片或音频素材文件**——箭头是代码画的矢量图形，音效是代码合成的波形，所以整个项目就是一堆 `.py`。

### 安装依赖

```bash
pip install pygame
```

或者：

```bash
pip install -r requirements.txt
```

### 运行

```bash
python main.py
```

### 运行后会生成的文件

程序会在**自己的目录**下自动创建两个存档文件，删掉它们就相当于恢复出厂设置：

| 文件 | 内容 | 什么时候写 |
|---|---|---|
| `progress.json` | 通关记录、每关最高分与最快用时 | 通关时 |
| `save.json` | 当前这一局：打到第几关、盘面剩哪些箭头、失误数、已用时、剩余提示/撤销次数、操作历史 | 每次操作后 |

两个文件的读写都做了异常处理：目录只读或文件损坏时游戏照常能玩，只是进度不保留，不会因此崩溃。

## 操作方式

| 操作 | 说明 |
|---|---|
| **鼠标左键点箭头** | 前进方向畅通则飞出消除；被挡住则不消除并扣一次失误 |
| **鼠标点按钮** | 所有功能都有按钮，不需要记快捷键 |
| **Esc** | 主菜单：退出游戏；游戏界面：返回选关；选关界面：返回主菜单 |
| **Ctrl + Z** | 撤销上一步（等同于点「撤销」按钮，属于便利快捷键） |

界面上各按钮的位置：

- **主菜单**：开始游戏 / 继续第 N 关（有存档时）、新游戏、选择关卡、退出游戏；右上角「音效：开 / 关」
- **游戏界面**：顶部「重新开始」「选择关卡」；底部「音效」「撤销 ×3」「提示 ×3」
- **选关界面**：关卡卡片、返回主菜单、右上角音效开关

## 游戏规则

1. 棋盘由若干**单格箭头**组成，方向只有上、下、左、右四种。
2. 点击某个箭头后，检查它**前进方向上、到棋盘边界之间**是否存在其他箭头：
   - **没有** → 箭头飞出棋盘并消失（带飞出动画）。
   - **有** → 箭头不能消除，会朝阻挡方向冲一下再弹回、闪白、晃动，并在底部给出文字提示。
3. 点击**被阻挡**的箭头消耗一次失误机会；点空格子、点棋盘外都不扣。
4. 清空本关全部箭头 → 通关，弹出结算面板。
5. 失误次数耗尽 → 本关失败，可重新开始。

判定只需要看**同一行或同一列、箭头与边界之间**有没有别的箭头，不考虑拐弯或连锁。

> **小提示**：这个游戏**不存在"点错就死"的情况**——消掉箭头只会让路径更空，所以此刻能飞出去的箭头，以后一定还能飞出去。卡住的时候一定有一个能点的箭头。

## 计分与计时

进入关卡后计时器开始走，本关结束时停表（结算动画的时间不算在内）。超过目标用时后用时胶囊会变橙色，提示已经没有速度奖励了。

```
本关得分 = 基础分 + 速度奖励 + 失误奖励 − 提示扣分 − 撤销扣分

基础分   = 800 + 难度分 × 12                 难度分见下文关卡表，越难的关基础分越高
速度奖励 = max(0, 目标用时 − 实际用时) × 15   目标用时 = 箭头数 × 4.5 秒
失误奖励 = 剩余失误次数 × 80
提示扣分 = 用掉的提示次数 × 150
撤销扣分 = 用掉的撤销次数 × 100
```

- 超时只是拿不到速度奖励，**不会倒扣**；扣分最多扣到 0 分，不会出现负分。
- **每关只保留最高分与最快用时**（两者独立记录，可以一次刷分、一次刷速），主菜单显示总分。
- 结算面板会把每一项都列出来，看得见分是怎么来的。

## 辅助功能

### 提示（每关 3 次）

点「提示」会用金色脉冲光环标出一个**当前就能消掉的箭头**。

因为"能飞出"这个性质是单调的，提示只要从当前可消的箭头里挑就永远安全。程序会优先挑**"消掉之后能解锁最多同伴"**的那一个——消一个能带出三个的箭头，比消一个孤立的更有价值。

### 撤销（每关 3 次）

点「撤销」退掉上一步：

- 上一步是成功消除 → 把箭头放回原位，并撤掉飞出动画
- 上一步是误点被挡 → 退回那次失误

失误刚好扣完时不会立刻判负（要等碰撞动画播完），**在这个窗口里撤销可以把这一关救回来**。

### 自动存档

- 打到一半直接关窗口也不会丢，下次打开主菜单会出现「继续第 N 关」
- 通关或失败后单局存档会被清掉（这一关已经结束了）
- 新游戏会清空通关记录与成绩（**需要点两次确认**，避免误触）

### 音效

7 个音效全部由代码合成，没有音频文件：箭头飞出、被挡住、提示、撤销、按钮点击、通关、失败。三个界面上都有「音效：开 / 关」按钮可以直接切换；检测不到音频设备时会显示「音效：无」并禁用按钮。

## 项目结构

```
游戏开发/
├── main.py        程序入口：窗口、主循环、界面切换、成绩与存档的联动
├── settings.py    全局配置：窗口尺寸、布局、配色、音量、动画参数、各功能开关
├── levels.py      12 个关卡的布局（用 ASCII 图描述）与难度分
├── game.py        游戏状态与规则判定：路径检测、失误计数、计时、提示选点
├── effects.py     动画对象与缓动函数：飞出、碰撞回弹、箭头入场
├── score.py       计分规则与时钟/分数格式化
├── progress.py    长期成绩：通关记录、每关最高分与最快用时
├── session.py     单局存档：没打完的这一关
├── audio.py       程序化音效合成（numpy 可选加速 + 纯 Python 回退）
├── ui.py          界面基础组件：中文字体、渐变与阴影、箭头贴图、按钮
├── scenes.py      三个界面：开始界面、游戏界面、选关界面，以及结算浮层
└── backdrop.py    动态背景：渐变、光晕、缓浮粒子、暗角
```

## 二次开发

### 改关卡

关卡用 ASCII 图写在 `levels.py` 里，`.` 是空格子，`^ v < >` 是四个方向的箭头：

```python
_level("初次搭箭", "入门", 17, 3, """
    ....
    .<.v
    ..>.
    .^..
"""),
```

参数依次是：关卡名、难度档、难度分、失误上限、布局。

改布局时**必须同时满足四条约束**，否则会出现"看着能玩其实无解"或画面糊成一团：

1. **任何两个箭头都不能上下左右相邻**，必须隔开至少一格（不然挤在一起看不清谁挡谁）。
2. **同一行 / 同一列里，同向箭头最多 2 个**（整行整列一个方向会很单调，也一眼看不出该先动哪个）。
3. **不能出现循环依赖**。只要箭头 A 前进路上第一个撞到的是 B，就记"A 依赖 B"（B 必须先消掉）；这个依赖关系里不能有环，有环就表示这几个箭头互相锁死，整关无解。最容易踩的是二元环（同一列上朝下 + 下朝上、同一行左朝右 + 右朝左），三元四元环更隐蔽。
4. **开局可动的箭头控制在 3 个到总数三分之一之间**。只剩一个能点会变成"唯一顺序"，玩家不用思考也能过，反而没难度。

> 第 3 条**光靠肉眼很难查出来**，改完关卡务必跑一遍穷举求解器验证。

### 调整难度与分数

| 想改什么 | 改哪里 |
|---|---|
| 失误次数上限 | `levels.py` 里每关的第 4 个参数 |
| 提示 / 撤销次数 | `settings.py` 的 `HINTS_PER_LEVEL`、`UNDOS_PER_LEVEL` |
| 各档扣分、基础分、速度奖励系数 | `settings.py` 里 `SCORE_` 开头的一组常量 |
| 关卡是否全部解锁 | `settings.py` 的 `UNLOCK_ALL_LEVELS` |
| 整体音量 | `settings.py` 的 `SFX_VOLUME`（0~1） |

### 改外观

配色、间距、圆角、动画时长都集中在 `settings.py`，改完直接生效。箭头颜色按方向区分（上蓝、下橙、左绿、右红），想统一成单色改 `ARROW_COLORS` 一处即可。

## 常见问题

**Q：没有声音？**
看界面上的音效按钮：显示「音效：无」说明系统没有可用音频设备（游戏会照常运行）；显示「音效：开」说明音效正常，可以点一下按钮确认状态会切换。

**Q：中文显示成方块？**
游戏在 Windows 上会自动使用微软雅黑。其他系统需要装一款中文字体（黑体 / 文泉驿微米黑等），`ui.py` 顶部的字体候选列表可以按需补充。

**Q：想重新开始？**
删掉程序目录下的 `progress.json` 和 `save.json` 即可；或者在主菜单点两次「新游戏」，它会清空通关记录与成绩并从第 1 关重新开始。

**Q：窗口能改大小吗？**
窗口固定为 920×760。布局全部由 `settings.py` 中的尺寸常量推导，改窗口大小后棋盘会自动居中并重新计算格子边长。
